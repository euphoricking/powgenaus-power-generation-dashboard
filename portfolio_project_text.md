# Portfolio Project Text: PowGenAUS

## Project Title

**PowGenAUS: Interactive Geospatial Dashboard for Analysing Power Generation in Australia**

## Short Project Card Description

PowGenAUS is an interactive Python dashboard for exploring power generation and power station capacity across Australia. Built with Streamlit, GeoPandas, Folium and Plotly, the application allows users to filter power stations by year, fuel type, state, capacity and station/owner name. It combines choropleth mapping, clustered station markers, interactive charts, summary indicators and downloadable data tables.

## Full Project Description

PowGenAUS was developed as a software development project within the MSc Applied Geoinformatics programme. The aim was to transform power generation data into an interactive geospatial dashboard that supports exploration of Australia’s energy infrastructure.

The application uses Python to load and clean the Global Power Plant Database, filter it to Australian records, convert station coordinates into geospatial point features and spatially join the power stations to Australian state boundaries. The processed data is then presented through a Streamlit dashboard with interactive filters, maps, charts and downloadable tables.

The dashboard allows users to explore where power stations are located, which fuel types dominate the selected dataset, how generation changes over time and how capacity and generation vary across Australian states and territories. The map component includes a state-level choropleth layer and optional clustered station markers with detailed popups for each power plant.
