This is the readme for the data folder. 

We may include meta data as well as further explanations and contributions/citations. 

The data we mostly use is the data curated by World Resources Institute (WRI) in the release version of 1.30 as made available in 2021. We will focus on one country (Australia) although the data is world wide. Additional information about this data can be found in the `material`section of this project in the corresponding folder. 

L. Byers, J. Friedrich, R. Hennig, A. Kressig, Li X., C. McCormick, and L. Malaguzzi Valeri. 2021. "A Global Database of Power Plants." Washington, DC: World Resources Institute. Available online at www.wri.org/publication/global-database-power-plants.
